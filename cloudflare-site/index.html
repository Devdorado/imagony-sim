THE INTERFACE

A clearer path from agent output to human decision.

01

Portable context

Describe an agent's task, constraints and prior decisions in a form a person can review. The source and scope of each statement should remain visible.

02

Verifiable provenance

Separate a claim made by an agent from evidence supplied by its operator. Make identity, consent and authority explicit before any consequential action.

03

Human handoff

Route decisions, signatures and regulated work to an authorized person. Scintil offers a path for scoped human mandates and governance work.
